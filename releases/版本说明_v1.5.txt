═══════════════════════════════════════════════════════════════
  ✨ 新功能
═══════════════════════════════════════════════════════════════

🎨 多图层水印系统
  - 支持添加无限制的水印图层
  - 每层独立配置混合模式和不透明度
  - 图层顺序自由调整
  - 数字越大的图层越在上面（覆盖下层）

🌈 Photoshop 混合模式
  - Normal (正常): Logo、文字水印
  - Screen (滤色): 光效、高光效果
  - Overlay (叠加): 纹理、图案叠加
  - Soft Light (柔光): 柔和艺术效果

🎚️ 类似 Photoshop 的内联编辑
  - Blend Mode 下拉选择
  - Opacity 数字输入框 (0-100)
  - 实时生效，无需确认
  - 选中图层即可编辑

⚡ 性能大幅优化
  - Alpha 通道预检查
  - 自适应缩放质量
  - 内存优化
  - 速度提升 40-60%

💾 配置自动保存
  - 图层信息自动保存
  - 下次启动自动恢复
  - 路径智能记忆

═══════════════════════════════════════════════════════════════
  📊 性能指标
═══════════════════════════════════════════════════════════════

单图层: 1920x1080 → 90ms  (提升 40%)
多图层: 1920x1080 + 3层 → 250ms (提升 44%)
批量处理: 100张图片 → 16秒 (相比v1.4节省14秒)
内存使用: 减少 28%

═══════════════════════════════════════════════════════════════
  🚀 快速开始
═══════════════════════════════════════════════════════════════

1. 解压缩包
   tar -xzf MultiLayerWatermark_v1.5_Distribution.tar.gz

2. 安装 Python 3.7+
   https://www.python.org/downloads/

3. 安装依赖
   pip install -r requirements.txt

4. 运行程序
   Windows: run_multilayer.bat
   Linux/Mac: ./run_multilayer.sh
   或: python src/watermark_app_multilayer.py

═══════════════════════════════════════════════════════════════
  🔨 打包成 exe
═══════════════════════════════════════════════════════════════

1. 安装 PyInstaller
   pip install pyinstaller

2. 执行打包
   pyinstaller build/MultiLayerWatermark_v1.5.spec --clean

3. 查找 exe
   dist/MultiLayerWatermark_v1.5.exe

详细说明见: BUILD_INSTRUCTIONS.md
