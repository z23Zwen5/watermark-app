# 🧠 智能水印算法 v1.3 - 技术文档

## 🎯 算法概述

Smart Watermark Algorithm 是一个基于颜色相似度检测的智能水印系统，能够自动检测水印与背景颜色的相似性，并在必要时动态调整水印颜色以实现最佳可见性。

## 🔬 核心技术原理

### 1. 颜色相似度检测

#### 欧几里得距离计算
```python
def calculate_color_distance(self, color1, color2):
    """计算两个颜色之间的欧几里得距离"""
    return sqrt(sum((c1 - c2) ** 2 for c1, c2 in zip(color1, color2)))
```

**原理**：
- 在RGB三维空间中计算两点间的直线距离
- 距离越小 = 颜色越相似
- 距离范围：0-441.67 (从(0,0,0)到(255,255,255))

#### 敏感度阈值
- **低敏感度(80-100)**: 只有极相似的颜色才会触发调整
- **中敏感度(30-50)**: 适中的相似度即触发调整
- **高敏感度(10-30)**: 轻微相似就会触发调整

### 2. 智能对比色生成

#### 亮度感知对比算法
```python
def get_contrasting_color(self, color):
    """获取对比色"""
    r, g, b = color[:3]
    
    # 计算亮度 (使用相对亮度公式)
    luminance = 0.299 * r + 0.587 * g + 0.114 * b
    
    if luminance < 128:
        # 原色较暗，返回更亮的对比色
        contrast_r = min(255, r + (255 - r) * 0.8)
        contrast_g = min(255, g + (255 - g) * 0.8)
        contrast_b = min(255, b + (255 - b) * 0.8)
    else:
        # 原色较亮，返回更暗的对比色
        contrast_r = max(0, r * 0.2)
        contrast_g = max(0, g * 0.2)
        contrast_b = max(0, b * 0.2)
    
    return (int(contrast_r), int(contrast_g), int(contrast_b))
```

**关键特性**：
- **感知亮度**: 使用人眼感知权重 (R:0.299, G:0.587, B:0.114)
- **动态调整**: 亮背景→暗水印，暗背景→亮水印
- **渐进对比**: 不是简单反色，而是智能渐进对比

## 🔧 使用示例

```
距离: √[(255-250)² + (255-250)² + (255-250)²] = 8.66
结果: 距离 < 30 → 触发智能调整 → 深色对比 (51,51,51)

```
